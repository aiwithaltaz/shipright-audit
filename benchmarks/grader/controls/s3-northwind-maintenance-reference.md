# Review: maintenance requests tool

Verdict: the data is useful, but the request cards are crowded, the most common action is buried, and several small visual and labeling problems add up. Fix the request cards first.

## What works (keep)

1. The Requests heading states the situation: "6 open requests · 2 overdue".
2. The Vendors table lists each trade with a tap-to-call phone number.
3. Property cards show occupancy as a bar plus "x of y units leased".
4. The current page is clearly highlighted in the navigation.

## Problems

| # | Problem | Where | Severity |
|---|---|---|---|
| 1 | A long blue pill holds a sentence ("Tenant says the noise started after the storm last night"); a note is used as a label. | Requests, window card | Minor |
| 2 | The "No hot water" card carries 7 pills, too many to scan. | Requests | Minor |
| 3 | The Urgent tab shows 5, but the Urgent page says there are no urgent requests. | Nav, Urgent | Major |
| 4 | Dates, icon buttons and "Assign vendor" sit at different heights across side-by-side request cards. | Requests grid | Polish |
| 5 | Property cards have a large empty gap between the address and the occupancy bar. | Properties | Polish |
| 6 | "Assign vendor", the main action, is buried at the bottom of each long card. | Requests | Minor |
| 7 | Each request card lists 7 detail lines, too dense for a list view. | Requests | Minor |
| 8 | The Filter menu has square corners while cards and buttons are rounded. | Filter menu | Polish |
| 9 | The Filter menu opens behind the fixed bottom bar, so options are covered. | Filter menu | Minor |
| 10 | The "Open" pill is orange on Requests but grey on Properties. | Requests, Properties | Minor |
| 11 | The "Reported" dates are light grey with low contrast. | Requests | Minor |
| 12 | The pencil and "..." buttons are icon-only with no label or accessible name. | Requests | Minor |
| 13 | The bottom bar says "Select requests", but there is no way to select any, and it shows on Properties and Vendors too. | Every page | Minor |

## Fix first

Slim the request cards to title, unit, status and one clear "Assign vendor" action near the top, and make the Urgent count match its page.
